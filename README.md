# KiluaAI

KiluaAI is an AI Instagram Scheduler that helps you schedule and auto-post Instagram Reels, Posts and Stories.

## Web app

Use KiluaAI on the web: https://social-scheduler-one-sandy.vercel.app

## Download the Android app

Get the latest Android app from [Releases](https://github.com/goyal3407-gif/kiluaai/releases).

## Install instructions

1. Download the APK from Releases.
2. Tap the downloaded APK file.
3. If Android asks, allow "install from this source".
4. Tap Install.
